# ADR-0006：未知原生图保存与目标组合转换

- 日期：2026-11-10
- 状态：已采纳（A12 结构交换验证）
- 关联：[ADR-0002](0002-统一插件接口与初步核心实现.md)、[ADR-0004](0004-统一节点功能定义与原生实现选择.md)、[ADR-0005](0005-MaterialX材质图核心与自定义节点扩展.md)

## 背景

A12 批量测试中，大量材质因未知功能或模式被阻断；只输出成功项不能满足完整盘点与后续规则开发。另一方面，Blender HSV 已能展开为标准数学图，目标渲染器未必有一对一节点。Maya 同一原生类型还可能承载多个标准功能，导入时的明确选择在原生回读时会变成歧义。

本决定细化 ADR-0005 的“文档可保存、目标可转换、外观已验证分别报告”，不改变材质范围及未来神经校正的产品边界。

## 决定

1. 保持 `materialx.export` 的完整语义要求。另提供 `materialx.preserve` 保存宿主读取的原生快照：自定义接口、未知实现声明、连线及元数据。未知类型变化也仅保存声明，不编造标准执行公式。
2. 保留文件标记 `iris_preservation_only=true`，响应 `conversion_supported=false`。目标转换必须以 `MATERIALX_PRESERVED_ONLY` 拒绝，不能创建中性色或部分成功图。原生保存不能计入语义转换成功数。
3. 原生文本与特殊数值显式编码。Base64 UTF-8 JSON 承载快照；非有限原生值使用可辨认标签。标准数值协议仍拒绝 NaN 和 Infinity。
4. 目标组合规则使用 `materialx_lowerings` 引用字典内联 NodeDef／NodeGraph，复用官方接口；仅移除经过常量条件核验的选择端口。核心检查类型、定义冲突、收敛、循环与规模，再展开为已有目标绑定。插件不实现条件公式或 HSV 公式。
5. 图片辅助组合先保持可核验边界，由图片读取器整组核验，不能被通用组合展开破坏。贴图通道能力由字典声明，实际文件与解码由宿主复核。
6. 允许 `identify` 的可选 `implementation_hint` 消解已创建原生图的实现歧义。提示必须匹配当前原生 ID 与配置；连接和常量仍从当前图读取，不能用提示或原文缓存代替原生证据。
7. 多宿主共用文件和传输流程放在 `plugins/core.py`；各宿主保留创建、资源实机检查、回滚与撤销责任。会话 JSON 行传输仍调用同一 `RelayService.handle`，不引入 HTTP。

## 替代方案

- 只保留错误 JSON：继续作为诊断，但不能单独呈现全量材质图结构。
- 给未知节点猜测标准功能：无法核实语义，不采用。
- 烘焙或中性色替代未知图：不能满足可编辑结构及明确失败要求，不采用。
- 在每个插件复制目标数学组合：会分裂规则，组合放入字典，由核心展开。
- 仅凭原生类型或保存的实现提示识别：无法发现配置变化，不采用。

## 后果

全量文档和成功转换可以独立交付；保存文件仍可能完全不能着色。原生快照不是完整场景备份，不包含未读取的 DCC 状态或缺失库的内容。标准图的目标支持范围继续由字典、宿主预检和实测共同限定。

A12 的 1,801 个材质输出 688 份标准／内联图与 1,113 份原生保留文件；50 个材质完成 Blender → Maya／C4D 与 Maya 再导出 → C4D 保存重开验证。证据与限制见 [A12 报告](../a12-materialx-interoperability.md)，没有新增渲染外观结论。

## 未决问题

未知程序化和混合功能的真实语义、RGBA 关联与过滤、更多坐标、原生组重建、任意未标记原生图的识别、更多宿主及版本、完整 C4D 原生导出和视觉校正仍需逐项证据。
