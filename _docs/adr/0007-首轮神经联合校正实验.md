# ADR-0007：首轮神经联合校正实验

- 日期：2026-11-10
- 状态：实验决定；模型效果待真实测试，不宣称已有效
- 关联：[ADR-0001](0001-材质转换与神经校正架构.md)、[ADR-0002](0002-统一插件接口与初步核心实现.md)、[ADR-0005](0005-MaterialX材质图核心与自定义节点扩展.md)、[ADR-0006](0006-未知原生图保存与目标组合转换.md)

## 背景

用户要求完成五项材质交换完善后开展第一遍神经训练，于 2026-11-11 09:00 验收。原有联合校正接口尚无真实模型；协议通过不能作为训练或外观证据。本机有 RTX 3090，Maya 2022 Arnold 的独立渲染探测已输出 EXR；Redshift 独立最小球体探测返回渲染失败，结构验证与渲染失败分别记录。

## 决定

1. 第一轮方向为 Blender 5.2.3 Cycles → Maya 2022.5／Arnold 7.2.5.3。使用已验证的标准表面和外部贴图范围；输入分布与允许调整项逐项记录，不能扩大为任意材质网络。
2. 实验框架为 PyTorch 2.7.1，运行在独立 Python 3.11 环境。优先准备 CUDA 版本；大型下载不稳定时可使用同版本 CPU 环境训练小型联合模型，并如实记录实际设备。它是本轮实验选择，不成为 DCC 或基础转换的必需依赖。环境、数据、权重及渲染放在仓库外，版本和运行命令可追溯。
3. 使用联合模型接收源材质参数、目标基础参数以及实际采样的贴图空间特征，输出一组受字典约束的材质参数变化。共享上下文同时影响多个输出，不能退化为独立固定偏移或一个全局系数。
4. 在独立、可丢弃的测试场景中固定可比几何、相机、灯光、曝光、线性色彩解释、采样与随机种子。校正前后使用完全相同条件；不修改用户场景或为目标单独优化非材质设置。
5. 离线渲染搜索可用于生成候选校正标签。保留原始字典基线、全部尝试、选择准则和搜索结果；劣于基线时使用零变化并明确记录。
6. 按材质／资产族划分训练、验证和测试；共享纹理、同一图的参数变体与不同视角不能跨集合。训练前冻结划分与随机种子，不依据测试结果调整超参数。
7. 模型只通过公开核心接口生成提案。字典限制、连接保护、有效数值、范围和原子应用继续生效；无模型、不支持输入或非法提案保留基础结果并报告。
8. 完成首轮训练的证据包括实际配对渲染、隔离清单、损失日志、可加载权重、独立测试及基线／校正对照。实验完成不等于模型有效：只有独立测试误差改善且超出重复渲染噪声，才能报告本次范围内的改善。

## 替代方案

- 使用合成参数偏移充当真实标签：不能证明跨渲染器校正，不采用。
- 先训练任意拓扑生成模型：数据和验证范围过大，本轮不采用。
- 通过调整灯光、曝光或全局色彩设置压低误差：超出产品边界，不采用。
- 用水印、缺失贴图或失败渲染训练：不能作为有效数据，不采用。
- 直接用 Redshift 渲染失败推断材质转换有误：证据范围不符，不采用。

## 后果

首轮模型仅覆盖清单中的渲染器版本、图范围及参数域；其他输入须拒绝校正或回退。训练依赖与基础核心隔离，公开业务协议和宿主边界保持。外观结果必须逐材质、逐条件报告，均值改善不能掩盖退化样本。

## 未决问题

模型结构、空间特征分辨率、样本量、损失权重及搜索预算须由本轮可复现配置固定；模型是否改善、对新材质族的泛化和更多渲染器方向需用结果回答。全量程序化图、连接驱动参数的资源修改及拓扑校正不因首轮训练自动获得支持。
