# ADR-0001：字典约束下、仅修改材质的跨渲染器联合校正

- 日期：2026-11-04
- 状态：提议
- 决策范围：项目边界、模块职责、校正与验证方向
- 确认程度：下述产品边界来自已有讨论；具体架构、训练方法及实施路线为初始提案，尚未实验验证。

## 背景

不同渲染器的材质难以快速互换。即使名称相似的参数被复制到目标端，也不能据此认定渲染外观一致。项目希望通过材质语义字典和轻量神经校正机制，减少转换后人工调整材质的工作。

讨论涉及 Redshift（RS）、Arnold 及用户提到的“cy”；“cy”的正式指代和具体版本尚待确认。此处不构成支持列表，也未选定首个转换方向。

用户所说的“权重倾向”不是一个统一数值，也不是每个参数独立的固定偏移，而是学习材质特征之间的关联，并据此生成整体调整方案。粗糙度和 AO 的例子用来说明可能涉及多个因素，不代表两者存在固定补偿关系。

## 已确认的产品边界

1. 以材质在渲染器中的整体表现为校正对象。整体意味着联合考虑材质内部的属性、层次和空间分布，不意味着修改整个场景或给所有参数乘同一个系数。
2. 只允许修改材质及其材质资源，不允许调整灯光、相机、环境、曝光、色彩管理或全局渲染设置来弥补误差。
3. 采用轻量神经系统学习关联校正的方向；不是默认引入语言大模型或对其进行微调。
4. 项目包含核心、字典和最小侵入的接入层。接入层采用原生插件、脚本或组合形式尚未决定。
5. 目标是尽可能接近的材质表现，实际支持范围和可接受误差需要通过实验定义，不承诺无条件完全等价。

## 提议的架构决定

### 1. 通过材质中间描述连接各渲染器

建议的基础链路：

```text
源 DCC / 渲染器材质
        ↓ 读取与解析
材质中间描述（语义、节点关系、贴图和层次）
        ↓ 字典转换
目标材质基础方案
        ↓ 联合校正
目标材质最终方案
        ↓ 接入层应用
目标 DCC / 渲染器材质
```

中间描述不能仅是一张参数表，应保留节点连接、贴图用途及色彩解释、坐标与单位约定、层次关系、源节点标识和不支持的信息。具体模式在选定首个转换范围后另行设计。

核心处理可序列化的材质描述和转换方案，不直接依赖 DCC 运行时。渲染器语义适配与 DCC 场景读写分别定义接口；具体部署方式暂不确定。

### 2. 字典给出语义和可执行边界

字典描述节点与参数含义、适用版本、转换公式、能力限制、近似方案及允许的调整操作。复杂算法由核心实现，字典引用明确的操作，不将字典扩展成任意执行脚本的容器。

字典需支持可追溯的转换报告：来源、使用的规则、近似处理及丢失的信息。版本管理保证同一输入能追溯到所用规则。

### 3. 神经校正器生成有关联的材质调整方案

初步考虑从零训练小型模型。输入可以包含源材质语义特征、目标基础方案、渲染器能力和版本信息；输出是受字典及材质有效范围约束的联合调整方案。

材质特征需要表达关键属性之间的关系，以及适用情况下的贴图分布或区域特征。模型不能仅凭贴图路径理解外观，也不能假定任意复杂材质图都能被少量特征完整概括。首版应限定可支持的材质图结构。

允许的操作候选包括参数变换、贴图重映射、已有层的混合关系调整，以及字典明确提供的节点替换方案。首版是否开放所有操作仍待实验确定。派生贴图应新建资源，保留源文件。

输出虽然最终落实为具体数据，但各项调整应由共同上下文联合决定，不能退化为互不关联的固定修正规则。暂不确定网络层数、特征维度、模型框架或是否采用图像输入。

后续若已有可复用模型，为新渲染器或材质类别继续训练，才讨论微调。常规推理仅生成材质调整方案，不默认在用户使用期间修改模型权重。

### 4. 渲染反馈用于验证整体效果

```text
源材质 → 源渲染参考 ───────────────┐
                                  ↓
目标基础材质 → 受约束的调整 → 目标渲染 → 比较外观
                    ↑                  │
                    └── 调整方案反馈 ──┘
```

每组源、目标对照应使用可比的几何体、光照、相机、曝光和色彩处理条件。这些条件可以在评估集的不同案例之间变化，但不能针对目标材质单独优化。工具可创建独立测试场景，不通过修改用户场景的非材质设置改善结果。

评价同时关注整体外观和相关局部表现，例如颜色分布、高光形态、反射过渡、透射与表面细节。具体指标、权重和阈值需要结合首批材质验证，不先写死一套通用损失函数。

AO 或底色不能成为任意误差的通用补偿手段。使用多个光照和视角检查校正是否仍然有效，避免只拟合一张参考图。

### 5. 分开设计训练和日常转换

推荐先评估以下数据路线：通过人工校正或离线参数搜索获得较优目标材质，再训练小模型预测联合调整方案。此路线不要求渲染器提供可微分接口；若改用其他训练方式，应单独论证。

日常转换优先考虑“字典基础转换 + 模型推理”，试渲染反馈作为待验证的可选细化能力。首版尚不承诺速度、误差或自动收敛。

数据记录应至少包含源材质描述、目标基础方案、校正方案、参考渲染、比较条件、规则版本和模型版本。训练、验证、测试按材质或资产族划分，不把同一材质的不同视角分到训练集和测试集。

### 6. 接入层保持最小侵入

接入层负责材质图读取、目标节点创建、资源引用、材质绑定、撤销和必要的渲染调用。转换语义与模型逻辑留在核心。

默认保留源材质，创建目标材质及派生资源，替换绑定时提供可撤销操作。源端未知节点、目标端缺失能力及失败状态应在报告中列明。

模型不可用、输出无效或超出已声明支持范围时，应明确报告并回退到字典基础方案，或标记为需要人工处理。不能把回退结果标为完成神经校正，也不假设模型能可靠识别所有未知材质。

## 替代方案与取舍

| 方案 | 优点 | 当前取舍 |
| --- | --- | --- |
| 仅按参数名或固定系数转换 | 实现简单，容易追踪 | 不能充分表达整体关联；仅可作为有限基线 |
| 仅使用字典规则 | 可解释，可控制 | 必须保留为基础转换与回退；外观补偿能力需验证 |
| 完全由模型直接生成任意目标节点图 | 可探索更大的表达空间 | 首版不采用；数据、约束和验证复杂度较高 |
| 每次转换都执行渲染搜索 | 可利用当前材质的渲染反馈 | 暂作为离线样本生成或可选细化方向，日常开销需实测 |
| 修改灯光、曝光或后期图像以匹配结果 | 能改变最终画面 | 超出仅调整材质的产品边界，不采用 |
| 微调现成大模型 | 可能复用已有表示能力 | 目前未确定适用模型或数据，不作为默认路线 |

## 后果与限制

- 字典、中间描述和模型需要分别版本化，接入层应报告兼容性。
- 增加渲染器不等于自动获得可靠外观匹配；仍需要规则、材质样本和渲染验证。
- 只有目标渲染器能表达的效果才能被准确重建，其他情况需要近似或明确告知不支持。
- 轻量模型的可行性取决于材质范围和特征设计；“小型”尚无参数量或耗时指标。
- 渲染样本生成、人工判断和版本差异会增加维护成本。
- 全局视觉误差降低不意味着所有局部特征都改善，需要保留各类差异证据。

## 建议的实施顺序与验收证据

1. **确定实验范围。** 选择一个 DCC、一个有方向的源到目标渲染器组合及版本，限定一组代表性材质；明确单位、色彩约定和评估条件。
2. **建立纯字典基线。** 完成读取、中间描述、目标创建与报告，验证节点关系和资源引用。此阶段不引入模型，也不宣称外观已经匹配。
3. **建立对照样本。** 在固定对照条件及多个测试条件下渲染，记录误差及人工认可的校正结果，明确数据划分。
4. **验证联合校正。** 将小模型与未校正的字典结果比较，同时检查整体与局部表现。在未参与训练的材质及测试条件上获得可重复改善后，再决定扩大范围。量化阈值需在该实验前约定。
5. **封装最小侵入接入层。** 根据所选 DCC 的 API、依赖部署及撤销能力，决定脚本、原生插件或组合形式。

## 未决问题

- 首个 DCC、源与目标渲染器及其版本；是否最终需要双向转换。
- “cy”的具体指代，以及首批应覆盖的材质类别和节点组合。
- 首版允许调整哪些参数、贴图变换、混合关系和节点结构。
- 中间描述模式、空间特征表达方式，以及是否需要图像作为模型输入。
- 训练样本来源、可用渲染资源和计算预算。
- 外观指标、可接受误差、推理耗时、回退标准和人工评价方式。
- 实现语言、模型框架、模型分发方式及插件部署方式。

以上未决项不阻碍先建立文档和版本管理，但相关实现不得把假设描述为已经确认的要求。
