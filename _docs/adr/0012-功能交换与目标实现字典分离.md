# ADR-0012：功能交换与目标实现字典分离

- 日期：2026-11-12
- 状态：已采纳（本轮实现及已列范围验证完成）
- 关联：[ADR-0004](0004-统一节点功能定义与原生实现选择.md)、[ADR-0005](0005-MaterialX材质图核心与自定义节点扩展.md)、[ADR-0006](0006-未知原生图保存与目标组合转换.md)、[ADR-0008](0008-可编辑图与贴图语义交换.md)

## 背景

一个 Blender HSV 在交换文档中携带 61 个数学节点，导入部分目标后进一步扩大。完整复刻源计算的策略增加了编辑成本，也把源实现选择带进了交换格式。用户明确要求：交换文件保存功能节点、通用参数与连接；原生映射和数学替代配方由各目标字典维护。

## 决定

1. 新导出的 `.mtlx` 优先使用官方功能节点，如 `colorcorrect`；官方未声明的细节使用版本化、类型明确的扩展数据保存。细节名称描述功能，不携带 DCC 或渲染器名称。连接与常量同等保留，不能只保存数值快照。
2. 功能定义与实现分离。核心导出不再把字典里的数学实现子图复制进交换文件。没有对应官方接口的功能可保存仅含接口的自定义 NodeDef；不能把这样的文件宣称为任意外部渲染器可独立执行。
3. 字典按宿主、渲染器和节点系统维护。导入优先选择原生映射，然后原生节点加辅助配方，最后完整替代配方。只有实际接口或行为存在差异时才限制软件版本。
4. 配方记录输入输出、节点、参数、连接、适用条件、已知差异和验证依据。数学展开只发生在目标转换的工作图中，不回写输入文档，也不借此自动扩展目标支持范围。
5. 没有目标映射或配方的细节参数可暂不应用，但须保留并明确报告。未知的主要功能或必需连接无法处理时仍阻断；不允许静默丢弃或把部分支持报告为完整转换。
6. 外部提供的计算图与历史内联图仍按其实际内容校验；不能仅凭名称或来源标记把用户已修改的图折叠成原生功能。新功能声明使用版本化接口校验，不再要求它携带目标实现。
7. 本决定调整 ADR-0005、ADR-0006、ADR-0008 中新导出文档携带实现图及依赖该图决定目标展开的方向；保留其历史理由和旧文档读取兼容。真实作者创建的数学节点和连线仍是材质内容，本决定不删除这些计算。

## 替代方案

- 继续导出完整源公式，再在目标中分组：没有解决交换内容与实现的耦合。
- 仅依据节点名称进行一对一替换：无法证明端口含义、范围和运算顺序，拒绝。
- 在插件里编写替代公式：规则分散，第三方接入无法复用，拒绝。
- 丢弃无法处理的细节参数：破坏往返和诊断，拒绝。

## 后果

交换图更接近作者使用的功能层级。目标字典成为实现选择的依据；缺少目标字典时不能假定扩展功能可执行。近似映射与严格计算配方必须分别报告，数值和结构验证不能代替渲染对照。

## 验证与未决问题

实现须验证紧凑导出、通用细节及动态连接、原生优先、目标配方隔离、未知细节报告、缺失配方阻断、历史文档兼容，以及修改后再导出读取当前参数。具体目标端口须有 API 或实机证据。本轮验收结果如下；未登记的功能、参数和宿主仍受字典能力限制，不宣称任意节点可转换或渲染外观等价。

### 2026-11-12 首条颜色校正链路

- 字典增加 `materialx_function_exports` 与 `materialx_function_implementations`：前者投影到通用接口，后者按原生、原生加辅助、完整配方选择。实现图继续存于目标字典的 `materialx_extensions`，基础运算组合继续复用 `materialx_lowerings`。
- HSV 交换为继承官方 `ND_colorcorrect_color3` 的 `ND_iris_colorcorrect_color3`。新增 `mix`、`hue_center`、`saturation_max`、`output_min`，保留类型和动态连接，不携带 NodeGraph。它是具有额外语义的扩展接口，外部渲染器不能仅按官方基类声称完整执行。
- Blender 对应单个原生 HSV；Maya Arnold 和 C4D Redshift 优先原生颜色校正加辅助配方。完整 HSV 公式仍留作目标字典的后备实现。未应用的细节产生 `MATERIALX_DETAIL_UNAPPLIED`，来源完整保留在转换响应中，并作为未启用存档随目标材质保存。
- 实际沥青材质只读转换后导出的新文档含 18 个主图节点、0 个实现子图；当前核心返回 Blender 7、Maya Arnold 10、C4D Redshift 16 个节点。源文件哈希未变。此计数不包含宿主另建的坐标、材质出口或整理节点。
- 独立 Maya 2022 / Arnold 7.2.2.1 / MtoA 5.3.2.1 的常量夹具通过创建、保存重开、29 个输入与 7 条连接核对，读取当前原生图并再次导出；总计 6 个目标节点。Blender 5.3.0 的五组 HSV 导出夹具通过常量、近灰、图片、动态连接、节点组及契约篡改拒绝检查。没有新增渲染外观结论。
- 未应用细节存档按来源文档 SHA-256 去重，包含端口及动态上游，去除前次存档以避免递归嵌套；不自动重放存档，不覆盖当前宿主中的有效参数。Blender 5.3.0 动态细节夹具经过保存重开、49 个输入与 9 条连接核对及再导出；Maya 的五组夹具也经过存档保存重开和再导出核对。当前只保证数据可恢复，未实现自动重新应用这些细节。
- Cinema 4D 2025.3.2 / Redshift 2025.3.0 的五组 HSV 夹具通过原生颜色校正创建、保存重开、端口与连线核对；随后从当前宿主图再导出，五份未应用细节存档均与导入时一致。场景条件未改动，没有渲染外观结论。
- 首阶段全量回归为 817 项通过、核心覆盖率 91%。该结果仅覆盖上述颜色校正及存档阶段，不能代替后续迁移的当前版本验收。

### 2026-11-12 静态功能与可变配置迁移

- 混合、Gamma、亮度对比度及数学辅助原语已接入同一交换／目标实现机制。混合使用继承官方 `mix` 的接口，额外保存 `blend_mode`、`clamp_factor`、`clamp_result`；Gamma 复用官方幂接口并明确非正输入、零指数行为；线性亮度对比度复用官方对比度接口并明确偏移和下限。各目标仍只声明已支持的行为，不因节点名字相似推定等价。
- Mix 与 MixRGB 的同等行为共用接口；Blender 目标选择现代 Mix 布局，并核对因子、两路颜色及钳制条件，不保证复现旧布局。Maya／Redshift 的普通线性混合优先已有原生绑定，带钳制时使用原生加辅助组合；其余已声明模式保留目标数学后备。
- 源生大于比较及 Redshift 分量提取导出为官方节点。Redshift Sign 的零值差异用通用 `zero_value` 细节表达，不能冒充标准 Sign。静态实现中的公式已抽取为共用生成函数，源原生绑定与目标配方显式调用，不在宿主适配器重复实现。
- 增加 `materialx_function_recipes`，目标明确选择 `color_ramp`／`normal_map` 配置编译器及可选原生绑定。新渐变及命名法线文档保存固定功能接口、`configuration` 字符串配置和连接，不携带实现图；配置规范化和公式生成只发生在工作库。旧内联配置仍核对完整实现，不能按标签信任被修改的图。
- 静态迁移的 61 项回归、可变配置的 38 项回归通过；另核验普通混合的原生优先及字典生成一致性。四组静态夹具在 Blender 5.3.0、Maya 2022／Arnold 7.2.2.1、C4D 2025.3.2／Redshift 2025.3.0 通过创建、保存重开和当前图再导出，未新增渲染外观结论。
- 实机发现 Blender 会静默钳制负颜色常量，适配器现写入后核对实际值并以 `NATIVE_VALUE_UNREPRESENTABLE` 拒绝变化；允许正常浮点存储误差。负常量拒绝与失败清理已实测，正值夹具通过。此检查不自动建立负常量的数学替代，负颜色运算的数值测试也不能代替宿主常量可写性证据。
- 四种渐变插值（LINEAR、EASE、CONSTANT、B_SPLINE）及命名法线共五组夹具，在上述三端均通过保存重开、参数／连线核对及当前图再导出。Blender 的命名法线使用真实测试网格与渲染默认 UV 集提供所有者证据。目标几何的 UV 对应及渲染外观仍由场景条件决定，不能由保存重开推定一致。
- 未支持的配置仅供忽略细节使用时归档；同一支路仍被主要输入使用时阻断。整数计数细节也可归档。新增验证覆盖该区别及配置编译器与原生绑定不匹配的拒绝。
- 纯官方 `ND_colorcorrect_color3` 的默认参数实例在 Maya Arnold、C4D Redshift 返回原生节点及警告；Blender 尚无对应的完整官方功能规则，明确阻断。本次的 Blender HSV 扩展接口支持不代表纯官方颜色校正的所有参数均受支持。
- 合并后的初轮 833 项检查发现旧数学夹具裁剪节点后遗留配置规则，已修复夹具并复验；未放宽运行时字典校验。最终代码冻结后的 837 项完整回归全部通过，核心覆盖率为 90.43%；覆盖率仅合并该版本的八个独立文件组。Ruff 检查及格式检查通过。检查包含公开 API、JSON 子进程和真实 HTTP 往返，没有新增渲染外观结论。
- 当前代码只读重转实际沥青样本，新交换文档仍为 18 个主图节点、0 个实现子图；三套目标核心图分别为 Blender 7、Maya Arnold 10、C4D Redshift 16 个节点。原样本 SHA-256 保持不变。完整结果留在忽略目录 `.local/function-exchange-20261112/final-validation.json`，新文档为同目录的 `material-functional-final.mtlx`；独立宿主测试场景及报告也留在忽略目录，未作为生产资源提交。
