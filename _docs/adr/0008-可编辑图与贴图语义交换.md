# ADR-0008：可编辑图与贴图语义交换

- 日期：2026-11-11
- 状态：已采纳（有界结构交换；外观仍须分别验证）
- 关联：[ADR-0005](0005-MaterialX材质图核心与自定义节点扩展.md)、[ADR-0006](0006-未知原生图保存与目标组合转换.md)、[ADR-0007](0007-首轮神经联合校正实验.md)

## 背景

实际 A12 图包含可变 ColorRamp、多输出分离、命名法线 UV、RGBA 和共享子图。仅保存标量或一对一节点绑定不能覆盖这些关系；完整数学展开也会增加编辑成本。另一方面，相同文件在不同宿主中的 Alpha 关联并不相同，不能把输出类型或节点数当作语义证明。

## 决定

1. 可变计算配方仍使用标准 NodeDef／NodeGraph。核心按严格配置生成配置摘要与内联标准数学，回导前重新生成并比较实际实现；不能仅凭来源标签折叠已被修改的计算。
2. 多输出连接保留实际输出选择。SDK 1.39.5 在部分嵌套出口展开中丢失选择时，在子图内增加单输出恒等端点，保持明确通道，不按节点名猜测。
3. 命名法线 UV 只在完整使用者证据确认其为全部对象的渲染默认 UV 时，允许展开为默认世界切线基底。缺少或冲突证据继续阻断。目标几何仍需提供相应 UV，不能从材质文档推断任意网格兼容。
4. 图片记录文件通道、源 Alpha 模式及必要的原生颜色关联。目标字典声明已核验格式的采样行为，核心生成显式乘除与独立 Alpha 连接；零 Alpha 的分母显式保护。Arnold PNG 与 Raw EXR 的实际采样证据分别记录；非 Raw RGBA EXR 当前异常，明确阻断。解码量化和边缘过滤仍可产生近似差异。
5. 静态 UV 组合在核心表达，宿主只读写声明的矩阵或采样器端口。Maya 使用当前 `aiUvTransform` 链；Redshift 的二维采样器次序及中心尚无渲染证据，声明近似并始终报告 `UV_SAMPLER_CONVENTION_UNVERIFIED`，不计外观成功。
6. 编辑元数据保留显示名、来源、位置和功能路径，不参与着色计算。自定义函数未连接的浮点／颜色接口可生成一份共享控制节点；内部实现常量不自动变成作者参数。Blender 使用标签和整理框，Maya 使用原生容器及属性发布，C4D 使用原生功能组及边界连接。它们不承诺恢复任意源 DCC 的完全相同原生组类型、界面或像素位置。
7. 原生回读始终读取当前计算值和连线。C4D 在私有克隆中展开当前组，并显式将未连接组输入的当前值传给内部端口；实际探测确认 SDK `Ungroup` 不自动传播这些值。用户原图保持不变。稳定身份与 SDK 克隆时的新 ID 分开处理。
8. 原生未标记图可显式选择唯一 `source_default` 以消解确有共同数值语义的绑定。默认 `identify` 行为保持严格；实现提示仍必须匹配当前原生 ID 和配置。
9. 文件资源通过公开枚举和完整映射改写。宿主资源包按内容哈希复制、使用相对路径，缺图须显式重定位，输出不覆盖；搬移后的宿主保存重开另行验证。核心不读取纹理像素或文件系统。
10. `materialx.diff` 比较文档计算字段、有效默认值、连接选择、URI、色彩解释及 Alpha 元数据，支持显式身份映射。它不证明任意图同构或渲染等价。能力查询区分字典声明、宿主预检与实际外观证据。
11. MaterialX 校正入口复用现有联合提案和原子应用。可选 `adjustment_range` 只约束校正，不收窄基础转换；本轮 Arnold 仅开放粗糙度与反射权重。调用者可提供声明式空间上下文，缺模型、超域或非法提案保留基础图。

## 替代方案

- 给不同宿主统一假定 RGB 与 Alpha 独立：真实 Arnold PNG 采样不符，不采用。
- 只保存原文件或原始 JSON，回导时重放：无法反映用户编辑，不采用。
- 为每个配方和源节点实例新增独立转换规则：重复维护公式，不采用。
- 将大量展开节点当作编辑性已经达标：不采用，增加功能分组和共享控制，并核验当前修改。
- 把颜色上下文全部拒绝或全部接受：均不采用；已知线性 Rec.709 可保留数值，未知全局上下文仍拒绝。

## 后果与证据

本轮实际 231 种 ColorRamp 配置与 Blender 原生评估一致；四类渐变在三宿主保存重开，Maya 发布控制及 C4D 功能组另有实机核对。全量源检查与最终批次、失败统计、原生导入器结果继续在验收报告中更新，不将过渡运行计入最终完成。

官方 MaterialX 1.39.5 样本保持原文、URL 和哈希。本项目适配器与 MtoA／C4D 原生导入入口分开测试；原生创建了表面节点也不意味着复杂上游全部核对或资源齐全。

## 未决问题

Redshift UV 的着色器次序、旋转中心与 Alpha 采样，非 Raw RGBA EXR、任意源组的完整原生重建、程序化／位移／混合着色器、更多精确版本，以及跨渲染器外观与神经模型泛化仍需独立证据。
