# ADR-0010：共享字典与运行时接口兼容检查

- 日期：2026-11-11
- 状态：已采纳
- 关联：[ADR-0003](0003-原生节点绑定与宿主验证.md)、[ADR-0005](0005-MaterialX材质图核心与自定义节点扩展.md)、[ADR-0009](0009-多传输服务接入.md)
- 依据：用户要求取消按每个软件精确版本定义字典的限制。本决定替代 ADR-0003 第 2 项的强制精确版本匹配；原验证记录及理由保留。

## 背景

原注册器以渲染器版本、宿主版本和节点系统组成精确键。字典只能列出已探测版本，导致节点接口没有变化的软件升级也被拒绝。Maya 适配器另行写死 Maya 2022 / MtoA 5.3.5.3，Blender 创建入口比较完整运行引用，进一步把验证环境当成了兼容边界。

本次本机 Blender 已是 5.3.0，使用 5.2.3 验证记录准备的目标图被旧相等检查拒绝；移除该门槛后，同一规则的两条图片法线／高度链路通过保存重开及读回。Maya 2022 / Arnold 7.2.5.3 与 Maya 2026 / Arnold 7.4.4.0 也可共用同一字典完成图片驱动标准表面的结构往返。这些是有界结构证据，不代表所有版本、节点或渲染外观兼容。

## 决定

1. 字典主要按 `renderer.id`、`host.id`、`host.node_system` 选择。无宿主的协议字典保留独立身份，不回退为任何宿主的默认字典。宿主或节点系统不同不能混用原生 code。
2. `renderer.versions`、`host.versions` 改为可选的精确限制；省略表示规则跨软件版本复用，不声明全部版本已经验证。兼容旧字典的非空版本列表，不自动扩大其声明；空列表、通配符、重复或非法版本拒绝。未知软件版本不会自动触发错误或需要确认的警告。
3. 注册时检查同一身份的规则范围是否重叠。共享字典与受限字典重叠同样拒绝，不能按加载顺序或“最接近版本”猜测。确有差异时优先在同一字典保留按实际 `native.id` 和 `native.properties` 识别的实现配置；没有真实差异证据不预建版本分支或复制整份字典。
4. 四份内置字典迁移为 `blender-cycles.json`、`maya-arnold.json`、`cinema4d-redshift.json`、`cinema4d-arnold.json`，内容修订版本为 `0.6.0`，不声明软件版本限制。原生探测目录仍使用带版本的文件名。生成器输出共享文件名，探测环境转入 `evidence.verified_environments`；`capabilities` 同时返回该证据与规则范围。
5. API v1 和材质协议保持。请求仍携带实际软件版本，用于源信息、目标结果及实验追踪；不得伪装成字典探测版本以通过匹配。字典自身的 `version` 和指纹继续追踪规则修订，不与软件版本混淆。
6. 宿主按当前节点接口读写。Maya 加载实际 MtoA，不再锁定版本；读写节点核对实际属性存在性与类型。Blender 使用当前模式的端口 ID、类型和属性检查；创建入口按实际环境查字典并核对接入身份。C4D 核对声明端口，沿用实际类型写入、提交后数值核对及连接验证。已存在的资源、未知节点／模式、失败清理和撤销检查继续执行。接口变化必须报告，不能静默丢掉端口。
7. 未使用的节点不会因其他节点缺失而禁用整份字典。接口核验发生在实际读取／创建相应节点时；导入检查通过仍不等于宿主创建成功。新材质创建失败按原有事务清理。
8. 基础规则的跨版本复用不扩大神经模型的训练域，也不取消 MaterialX SDK 的固定依赖。模型仍核验实际目标、字典修订及训练上下文；旧模型不匹配时保留基础结果并明确报告，需要新的实验依据才能迁移权重。

## 替代方案

- 每个补丁版本复制字典：重复维护共同规则，并继续阻断未经列举的兼容版本，不采用。
- 把所有版本替换为 `*`：不能清楚区分省略限制与已验证范围，不采用。
- 删除所有版本信息或伪报运行版本：失去复现与外观实验条件，不采用。
- 自动选择版本号最接近的字典：版本距离不能证明接口或含义兼容，不采用。
- 仅改字典文件名：注册器及宿主硬编码门槛仍在，不能解决问题。

## 后果

常规升级可继续复用共同规则，探测证据无需随每次升级复制。显式受限的第三方旧字典保持原行为。迁移时应移走旧的四份运行时字典，不能将新旧文件同时放进扫描目录；重叠会明确报错。历史 `catalogs/` 继续保留。

节点类型相同也可能存在渲染算法或默认行为变化，运行时检查不能证明视觉等价。发现真实不兼容后，应补充具体节点差异、失败样本和验证证据，不能重新用未经分析的全局版本锁代替处理。

## 验证

- `_tests/test_dictionary_compatibility.py`：跨版本转换、无宿主共享规则、身份隔离、旧限制、重叠拒绝、能力证据、未知节点、真实 JSON 子进程及四份内置字典的 MaterialX 往返。
- `_tests/test_host_compatibility.py`：Maya 加载与版本变化、属性缺失及类型变化；Blender 插口类型／输出缺失；C4D 全部声明端口检查。
- `_tests/test_http_e2e.py`：真实本机 HTTP 的已验证版本与变化版本请求使用相同业务规则。
- 独立实机结果及完整回归统计见[字典文档](../native-dictionaries.md#跨版本共享与验证记录)。

## 未决问题

端口保持不变但着色语义改变的识别、更多旧版本及插件组合的实测，以及跨版本渲染对照仍需独立证据。当前没有证据需要引入通用版本范围解析或节点补丁语言，后续按实际差异确定。
